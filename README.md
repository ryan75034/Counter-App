# Counter App

A simple counter app built with HTML, CSS, and JavaScript.
The app increases, decreases, and resets a number with a
slot-machine style animation.

## Features
- Increase and decrease counter
- Reset button
- Slot-machine rolling animation
- Status text changes based on value

## Technologies Used
- HTML
- CSS (Grid + Animations)
- JavaScript (DOM manipulation)

## What I Learned
- Using querySelector to access DOM elements
- Updating UI based on state
- Creating animations with CSS and JavaScript
- Writing clean, readable code

## How to Run
1. Clone the repository
2. Open `index.html` in a browser
